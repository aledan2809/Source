# Source — AI Sourcing Platform

AI-powered procurement platform that helps you find suppliers, generate RFQ documents, and create personalized emails. Describe what you need to buy or rent, and get complete sourcing packages.

- **Smart AI Interpretation** — Clarifying questions until 100% understanding

- **Feedback Loop** — Refine results based on your feedback

### Recomandări next steps

1. **Adaugă teste** — cel puțin teste de integrare pentru API endpoints + test E2E pentru fluxul principal
2. **Forțează autentificarea** — nu permite acces fără token în producție; adaugă validare la startup
3. **Migrează la SQLite/PostgreSQL** — JSON files nu sunt viabile pentru producție
4. **Mută upload-urile** — din `public/` într-un director non-public, servite prin API cu auth check
5. **Adaugă `/api/health`** — necesar pentru monitoring și deployment checks
6. **Adaugă logging structurat** — winston sau pino pentru producție
7. **Configurează Docker + CI/CD** — pentru deployment reproductibil
