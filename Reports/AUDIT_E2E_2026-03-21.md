### 4.4 Securitate

| Risc | Severitate | Detalii |
|------|-----------|---------|
| Upload fișiere fără autentificare | Medie | Oricine poate posta fișiere în `/api/upload` — directorul `public/uploads/` este public |
| Fără rate limiting | Medie | Orice request poate declanșa o instanță Claude CLI (cost + CPU) |
| `ANTHROPIC_API_KEY` șters din env pentru CLI | Scăzut | Corect implementat — CLI-ul folosește sesiunea proprie, nu cheia API |
| Fișiere uploadate accesibile public | Medie | `public/uploads/` nu are protecție — oricine cu UUID-ul sesiunii poate accesa fișierele |
| Fără sanitizare input în prompts | Medie | Descrierea utilizatorului este inserată direct în promptul Claude fără escape — risc teoretic de prompt injection |
| Nu există autentificare | Critică | Aplicația nu are niciun sistem de login — oricine accesează URL-ul poate folosi serviciul și genera costuri |
| Fișiere JSON expuse indirect | Scăzut | `src/data/` nu este în `public/`, deci nu e accesibil direct via browser |
| Hardcoded port NeMo: 7779 | Scăzut | Port hardcodat fără config externalizată |

**Nu există:**
- `.env` file detectat (variabile de mediu)
- Hardcoded credentials (corect)
- SQL injection (nu există DB SQL)
- CSRF protection (Next.js server actions nu sunt folosite, dar API routes sunt vulnerabile fără origin check)

### 4.8 Probleme Critice Identificate în Cod

1. **Guardrails bypass în producție (search-log.json):** Înregistrarea cu ID `ed5ef6c1` conține furnizori care au trecut prin filtrele post-generare dar sunt în mod evident agregatori (OLX, Alibaba, Dedeman, Praktiker, Made-in-China). Aceasta indică că filtrul `AGGREGATOR_DOMAINS` din `generate/route.ts` a eșuat sau nu a fost activ la momentul generării respective. Datele false rămân persistate fără mecanism de curățare.

2. **Race condition la scrieri concurente:** `search-log.json` este citit și rescris complet la fiecare operație (feedback, generate). Dacă două generări rulează simultan, a doua scriere poate suprascrie modificările primei, pierzând date.

3. **Fără autentificare sau rate limiting:** Claude CLI este invocat ca subprocess — fiecare request `/api/source/generate` pornește un proces care poate rula 60–180 secunde. Fără protecție, un atacator poate lansa zeci de procese simultan.

4. **README metadata neactualizată:** `layout.tsx` afișează titlul "Create Next App" în browser tab și în search engine results — impactează SEO și percepția profesională.

5. **Prețuri AI haluciante în date persistate:** În search-log.json, mai multe înregistrări conțin `priceMin/priceMax` setate de AI (nu extrase real din pagini), deși codul din `generate/route.ts` încearcă explicit să le elimine dacă nu sunt scraped. Această inconsistență indică că înregistrările vechi au fost generate înainte de logica de curățare prețuri.

### Ce este parțial implementat

- **Web search pentru URL-uri reale:** Funcțional, dar calitatea variază — în unele sesiuni din search-log.json s-au returnat homepage-uri ca `productUrl`, deși există logică de respingere a acestora. Verificarea URL-urilor nu este 100% fiabilă.

- **NeMo Guardrails:** Integrat, dar serviciul este opțional și extern — funcționalitatea de guardrails depinde de un proces separat care nu este pornit automat.

### Recomandări Concrete pentru Next Steps

1. **Autentificare imediată:** Adaugă NextAuth.js sau un middleware simplu de parolă shared (pentru uz intern) — chiar și o variabilă de mediu `ACCESS_TOKEN` verificată pe middleware poate bloca accesul neautorizat rapid.

2. **Migrare persistență:** Înlocuiește fișierele JSON cu SQLite (via Prisma sau `better-sqlite3`) — zero infrastructure overhead, elimină race conditions, permite queries reale.

3. **Rate limiting:** Adaugă un contor in-memory (sau Redis) pe IP/sesiune pentru `/api/source/generate` — max 3 cereri simultane, refuză cu 429 dacă limita e depășită.

4. **Actualizare metadata:** `layout.tsx` — titlu "Source — AI Sourcing Platform", descriere relevantă pentru SEO.

5. **Componentizare UI:** Extrage formularul de sourcing în `components/SourcingForm.tsx`, results tabs în `components/ResultsTabs/`, și funcția `runClaude` în `lib/claude.ts` — reduce duplicarea și facilitează testarea.

6. **Variabile de configurare externalizate:** Portul NeMo (7779), timeout-urile (60s, 120s, 180s, 3 minute), și limita de clarificări (3 runde) trebuie mutate în `.env` sau un fișier de config.

7. **Export PDF server-side:** Folosește `@react-pdf/renderer` sau `puppeteer` pentru a genera un PDF real din brief, în loc de `window.print()`.

8. **Headers securitate Next.js:** Adaugă în `next.config.ts`: `X-Frame-Options`, `Content-Security-Policy`, `X-Content-Type-Options`, și limitare dimensiune body pentru upload.
